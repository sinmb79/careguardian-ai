# 생활후견 AI 비공개 테스트 운영 가이드

- 대상 버전: Android `1.1.0` (`versionCode 7` 이상 AAB)
- 제품 위치: Productivity / 타깃 연령 18세 이상 / 기능 제한형 로컬 문서 정리 도구 (IARC 콘텐츠 등급은 설문 후 확정)
- 데이터 범위: **합성·비민감 생활 일정과 메모만 허용**
- 테스트 시작 전제: 현재 버전 final AAB, AAB 정적 검사, Android-native 스크린샷, Play 등록 문안·선언·`docs/store-listing.md` Data safety 입력값 대조 완료

> 실제 개인정보, 민감정보, 계정 자격증명, 연락처, 위치 정보는 입력하지 마세요. 로컬 AI는 일반 생활 문서 정리만 돕고 결과를 자동 저장하지 않습니다.

Samsung/Pixel 물리 기기 증거는 이 합성 데이터 비공개 테스트 중 수집합니다. 물리 기기 검증은 제출·운영 시작의 절대 선행 조건은 아니지만, 실제 개인정보·민감정보 단계와 정식 출시 전에는 반드시 완료하고 중대한 발견사항을 해소해야 합니다.

## 1. 참여 전에 확인할 것

1. Play 초대에 사용한 Google 계정으로 참여하고 공식 opt-in 링크에서 설치합니다. APK나 AAB를 메신저로 배포하지 않습니다.
2. 화면 잠금과 기기 인증을 설정합니다.
3. 모델을 설치할 경우, 고정 Hugging Face GGUF 파일 요청에서 IP 주소와 일반 네트워크 메타데이터가 호스트에 보일 수 있음을 확인합니다. 프롬프트와 생성 결과는 전송하지 않습니다.
4. 아래 예시처럼 합성 데이터만 사용합니다.

### Play App access 안내

새 설치에는 저장된 자료가 없으므로 잠금 없이 빈 작업공간으로 진입합니다. 저장 후 다시 열 때에는 테스트 참여자 자신의 기기 PIN 또는 생체 인증으로 열립니다. 앱 계정, 공용 암호, 별도 테스트 계정은 없습니다. 생체 인증을 사용하지 않는 기기의 PIN fallback도 물리 기기 검증 기록으로 남겨야 합니다.

| 항목 | 허용 예시 | 금지 예시 |
|---|---|---|
| 작업공간 | `테스트 작업공간 A` | 본인·가족 실명 |
| 일정 | `가상 외출 준비 · 2026-08-03` | 실제 민감 일정 |
| 목록 | `가상 장보기 목록` | 실제 주소·계정정보 |
| AI 입력 | `회의 메모를 체크리스트로 정리` | 실제 개인정보 포함 문서 |

## 2. 핵심 테스트 시나리오

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| CT-01 | 첫 실행 | 빈 개인 작업공간과 데이터 제한 안내가 표시됨 |
| CT-02 | 작업공간·기능 추가 | 일반 제목과 제한된 선언형 기능만 저장됨 |
| CT-03 | 일반 일정 알림 | 잠금 화면에는 일반 제목만 표시되고, data payload에는 제목·메모 없이 `taskId`만 남음 |
| CT-04 | 알림 권한 거부 | 저장 성공과 알림 예약 실패가 구분되어 표시됨 |
| CT-05 | 백그라운드 전환·재진입 | 인증 전 작업공간 내용이 보이지 않음 |
| CT-06 | 화면 캡처·최근 앱 | 보호 화면이 차단되는지 확인하고 접근성 충돌을 기록함 |
| CT-07 | 로컬 AI 미설치 | 일반 생활 기능이 독립적으로 동작함 |
| CT-08 | 모델 설치 동의 | 고정 출처·크기·SHA-256·라이선스 정보가 보이고 임의 URL 설치가 없음 |
| CT-09 | AI 결과 | 자동 저장 없이 미리보기·승인·삭제 선택지가 분리됨 |
| CT-10 | 전체 삭제 | 추론·일반 알림·모델·부분 파일·작업공간·키가 제거되고 빈 상태로 돌아감 |
| CT-11 | 삭제 후 재시작 | 삭제한 합성 데이터가 복구되지 않음 |

### 로컬 AI 0.5B 품질 QA

현재 Android exact-source 대표 합성 원문 QA에서 요약(원문 발췌), 모델 재로딩, 무결성 검사는 통과했고 문장 다듬기·제목 제안·체크리스트 초안은 엄격한 출력 검증에 의해 `output_blocked` 처리되었습니다. 0.5B 결과는 best-effort이며 모든 결과는 엄격한 정책·원문 근거 검증을 거칩니다. 통과하지 못한 결과는 원문을 변경하지 않고 폐기되며 같은 동작을 다시 시도할 수 있습니다. 비공개 테스트에서는 네 동작의 성공률과 Samsung/Pixel 등 기기별 결과 품질을 기록합니다.

## 3. 운영 순서

| 기간 | 확인 내용 |
|---|---|
| D0 | 새 AAB 설치, 정책 링크, 데이터 제한과 기본 화면 확인 |
| D1–D3 | 저장·잠금·인증·알림 권한 허용/거부·전체 삭제 |
| D4–D7 | 재부팅, 절전, DND, 백그라운드와 일반 알림 관찰 |
| D8–D11 | 모델 미설치 경로, 설치 동의·중단·손상 파일 차단, AI 승인 전 미저장 |
| D12–D14 | 회귀, 접근성 문구, Samsung/Pixel 결과와 중대한 문제 미해결 여부 |

## 5. 즉시 중단 기준

- 인증 전 합성 작업공간 내용이 표시됨
- DB·로그·알림 payload에 합성 입력값 평문이 노출됨
- 전체 삭제 후 작업공간·키·모델·부분 파일·일반 알림이 남음
- 모델 설치 외 선언하지 않은 네트워크 전송이 확인됨
- 프롬프트·출력이 모델 다운로드 요청으로 전송됨
- 임의 URL·코드·플러그인이 실행되거나, 로컬 AI 결과가 승인 없이 저장됨
- 반복 크래시, 데이터 손상, 인증 불능이 확인됨

## 6. Play Console 적용 전 확인

기존 대기 변경과 자산은 final AAB·문안·Android-native 스크린샷·feature graphic으로 완전히 교체합니다. 새 제출은 Productivity, 타깃 연령 18세 이상, Health apps declaration `My app doesn't provide any health features`로 작성하며, IARC 콘텐츠 등급은 설문 후 확정합니다. Data safety는 `docs/store-listing.md`의 입력값을 final AAB 정적 검사와 고정 네트워크 경로 계약으로 대조합니다. 이 조건을 충족하면 합성 데이터 비공개 테스트 제출·운영을 시작할 수 있습니다.

Play Console의 실제 opt-in 참여자 수는 목록 인원과 별도로 매일 확인합니다. 테스트 중 Samsung/Pixel 관찰이 Console 입력과 다르면 즉시 운영을 중단하고 값을 보수적으로 수정합니다. 물리 기기 증거 완료 전 실제 개인정보·민감정보 사용과 정식 출시는 `NO-GO`입니다.

출시 전에는 이전 저장 자료·알림이 전체 삭제에 포함되는지, `index.html` CSP, production 의존성 위험 승인을 현재 증거로 확인해야 합니다. `expo-notifications` 제거 후 `npm audit --omit=dev`의 2026-07-31 관찰값은 Critical 0 / High 19 / Moderate 9이며, AAB 도달 가능성·owner·검토일·만료일이 있는 risk acceptance gate 전에는 안전 판정으로 해석하지 않습니다.
