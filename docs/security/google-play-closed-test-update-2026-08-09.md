# Google Play Alpha 1.1.1 (8) 업데이트 제출 증거

- 확인일: 2026-08-09 (Asia/Seoul)
- 트랙: 비공개 테스트 `Alpha`
- release: `1.1.1 (8) - 기기 인증 복구`
- 현재 상태: **검토 중**
- 판정: **AAB 업로드·출시 정보 저장·Google 검토 제출 PASS**

이 기록은 앱 종료 후 재실행한 뒤 기기 인증을 완료해도 잠금 화면에서 넘어가지 않던 문제의 수정본을 기존 합성 데이터 비공개 테스트에 업데이트한 결과입니다. Google의 검토 완료나 테스터 대상 제공 완료를 뜻하지 않습니다.

## 2. 업로드와 Play 정적 인식

[Android AAB 검증 증거](./android-aab-evidence-2026-08-09.md)의 final AAB를 업로드했습니다.

| 항목 | 확인값 |
|---|---|
| 파일 | `life-steward-ai-1.1.1-vc8.aab` |
| 크기 | `98,668,393` bytes |
| SHA-256 | `69c6a7f1dd62a4e47291c9c7cce76e32eca6909fcdf2144d2f33ad6c09dc2575` |
| Play 인식 버전 | `8 (1.1.1)` |
| min SDK / target SDK | `24` / `36` |
| 폼 팩터 / ABI / 필수 기능 | `4` / `4` / `1` |

이전 `7 (1.1.0)`과 비교한 지원 기기 수는 전화 `12,439`, 태블릿 `6,639`, TV `6`, 차량 `25`, Chromebook `72`, Android XR `1`이며, 더 이상 지원되지 않거나 새로 추가된 기기는 모두 `0`으로 표시되었습니다.

Play 검증에는 오류 없이 경고 1개가 있었습니다. 경고는 R8/ProGuard를 사용할 때 필요한 가독화 mapping 파일이 없다는 내용입니다. 동일 source SHA의 생성 Gradle 계약은 `android.enableMinifyInReleaseBuilds` 기본값이 `false`이고 release `minifyEnabled`가 그 값에 연결됨을 확인했으므로, 이 후보는 난독화된 R8 산출물의 mapping 파일을 누락한 상태가 아닙니다. 경고는 제출을 차단하지 않았으며 향후 R8을 활성화할 때 mapping 업로드를 함께 적용합니다.

## 4. 제출 결과와 진행 유지

출시 변경사항을 저장한 뒤 게시 개요의 `검토를 위해 변경사항 1개 제출`을 실행하고 최종 전송 대화상자를 확인했습니다. Play Console은 `검토를 위해 변경사항 1개를 전송했습니다.`라고 응답했습니다.

제출 직후 상태는 다음과 같습니다.

| 항목 | 확인값 |
|---|---|
| 업데이트 상태 | 검토 중 |
| Alpha 새 release | `1.1.1 (8) - 기기 인증 복구` / 검토 중 |
| 기존 제공 release | `1.1.0 (7) - 생활후견 비공개 테스트` / 선택한 테스터에게 계속 제공 |
| 참여자 / 운영 일수 | 12명 / 8일 |

따라서 AAB 업데이트 제출로 기존 14일 비공개 테스트 진행이 초기화되지 않았음을 제출 직후 화면에서 확인했습니다. Google은 전송 대화상자에서 검토가 일반적으로 7일 이내에 끝나지만 더 오래 걸릴 수 있다고 안내했습니다. 승인 전까지 `1.1.1 (8)`의 테스터 제공 완료를 주장하지 않습니다.
